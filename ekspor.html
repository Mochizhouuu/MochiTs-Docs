Jendela Simpan

Ketuk ikon ekspor di Editor. Akan muncul jendela dengan pilihan berikut:

  • Nama Output / Nama Proyek: nama file hasil ekspor. Kalau diubah, judul proyek ikut berubah.
  • Format: PNG, JPEG, WEBP, atau MTS.
  • Kualitas: hanya muncul untuk JPEG dan WEBP, dari 10 sampai 100%.
  • Folder tujuan: folder yang sudah diatur di Settings. Kalau belum ada, MochiTs meminta kamu memilih folder saat menekan Simpan & Ekspor.

Memilih format

FormatCocok untukCatatan
PNG Gambar dengan bagian transparan, teks kecil, atau garis tipis. Tidak mengurangi kualitas, jadi ukuran filenya paling besar. Pengatur kualitas tidak muncul.
JPEG Unggahan sehari-hari yang ingin ukurannya lebih kecil. Kualitas gambar sedikit dikurangi dan bagian transparan tidak bisa disimpan. Atur kualitas 10 sampai 100%.
WEBP Situs web atau berbagi gambar dengan ukuran kecil. Di Android 11 ke atas, kualitas gambar sedikit dikurangi agar file lebih kecil. Atur kualitas 10 sampai 100%.
MTS Menyimpan proyek utuh, memindahkannya ke HP lain, atau melanjutkan editing nanti. Ini file proyek, bukan gambar. Bisa dibuka lagi atau dimasukkan ke ZIP.
Ukuran hasil. Gambar mengikuti ukuran kanvas proyek, bukan seberapa besar gambar terlihat di layar. Kalau hasil terasa kecil, periksa lebar dan tinggi proyek.

Folder tujuan

Atur folder default di Settings → Folder Output Default (Export). MochiTs memakai pemilih folder bawaan Android, jadi aplikasi tidak meminta izin ke seluruh penyimpanan.

  • Kalau folder default masih bisa diakses, hasil langsung disimpan ke sana.
  • Kalau belum diatur atau izinnya dicabut, Android meminta kamu memilih folder setiap kali ekspor.
  • File dengan nama yang sama akan ditimpa. Ganti nama output kalau ingin menyimpan beberapa versi.
  • File ditulis dulu ke penyimpanan sementara, lalu dipindahkan ke folder tujuan.
Nama file. Ekstensi mengikuti format yang dipilih: .png, .jpeg, .webp, atau .mts. Hindari karakter / dan : pada nama output.

File proyek .mts

File .mts menyimpan proyek secara utuh: gambar dasar, lapisan, dan semua pengaturan editing. Gunakan untuk:

  • mencadangkan proyek sebelum mencoba perubahan besar,
  • memindahkan proyek ke perangkat lain,
  • mengirim proyek ke rekan tanpa kehilangan lapisan.

File ini bisa dibuka langsung dari aplikasi File, atau dimasukkan ke ZIP bersama gambar lain. Saat ZIP diimpor, file .mts tetap dikenali sebagai proyek yang bisa diedit.

Tips kualitas

  1. Gunakan PNG untuk teks berukuran kecil agar tepi huruf tetap tajam.
  2. Untuk JPEG atau WEBP, kualitas 85 sampai 95% biasanya sudah cukup. Di bawah 70%, tepi huruf mulai terlihat pecah.
  3. Simpan versi PNG sebagai arsip, lalu versi WEBP untuk diunggah.
  4. Kalau hasil berbeda dari kanvas, periksa lapisan yang disembunyikan atau berada di luar batas kanvas.
