Ekspor

Simpan hasil sebagai gambar siap unggah, atau sebagai bundel proyek yang bisa dibuka dan diedit lagi.

Dialog Simpan Sebagai

Ketuk ikon ekspor di Editor. Dialog berisi:

  • Nama Output / Nama Proyek — dipakai sebagai nama file sekaligus mengganti judul proyek bila berbeda.
  • Format — PNG, JPEG, WEBP, atau MTS.
  • Kualitas — hanya muncul untuk JPEG dan WEBP, rentang 10–100%.
  • Folder tujuan — folder default dari Settings, atau pilih folder saat menekan Simpan & Ekspor jika belum diatur.

Memilih format

FormatCocok untukCatatan
PNG Hasil akhir dengan area transparan, teks tajam, atau garis tipis. Lossless; slider kualitas tidak ditampilkan. Ukuran file paling besar.
JPEG Unggahan umum, ukuran file lebih kecil. Lossy; tidak mendukung transparansi. Kualitas 10–100%.
WEBP Ukuran kecil dengan kualitas baik untuk web. Lossy pada Android 11+; kualitas 10–100%.
MTS Arsip proyek, pindah perangkat, atau melanjutkan editing nanti. Bundel proyek, bukan gambar. Bisa diimpor kembali lewat ZIP atau dibuka langsung.
Resolusi. Gambar diekspor pada ukuran kanvas proyek, bukan ukuran layar saat zoom. Periksa lebar/tinggi proyek bila hasil terasa kecil.

Folder tujuan

Atur folder default di Settings → Folder Output Default (Export). MochiTs memakai Storage Access Framework, jadi tidak perlu izin penyimpanan penuh.

  • Jika folder default masih valid, ekspor langsung ditulis ke sana.
  • Jika belum diatur atau aksesnya dicabut, pemilih folder Android terbuka setiap kali ekspor.
  • File dengan nama yang sama di folder tujuan akan ditimpa. Ganti nama output bila ingin menyimpan beberapa versi.
  • File ditulis lewat file sementara di cache, lalu disalin ke folder tujuan dan dibersihkan.
Nama file. Ekstensi mengikuti format yang dipilih: .png, .jpeg, .webp, atau .mts. Hindari karakter / dan : pada nama output.

Bundel .mts

Format MTS menyimpan proyek lengkap: gambar dasar, layer, dan data editing. Gunakan untuk:

  • mencadangkan proyek sebelum eksperimen besar,
  • memindahkan proyek ke perangkat lain,
  • mengirim proyek ke rekan tanpa kehilangan layer.

Bundel bisa dibuka dari file manager (langsung menjadi proyek) atau dimasukkan ke ZIP bersama gambar lain; saat ZIP diimpor, bundel tetap dikenali sebagai proyek editable.

Tips kualitas

  1. Gunakan PNG untuk teks berukuran kecil agar tepi huruf tetap tajam.
  2. Untuk WEBP/JPEG, kualitas 85–95% biasanya cukup; di bawah 70% tepi teks mulai terlihat pecah.
  3. Ekspor versi PNG dulu sebagai arsip, lalu versi WEBP untuk diunggah.
  4. Jika hasil terlihat berbeda dari kanvas, periksa layer yang tersembunyi atau terpotong di luar batas kanvas.
