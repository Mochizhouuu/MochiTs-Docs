Alat

Cek Script

Periksa naskah Script TL sebelum dipakai. Semua proses berjalan di browser.

Aturan naskah

  • Baris seperti P1 atau P12 membuka halaman baru. Baris sebelum pemisah pertama diabaikan.
  • Simbol dikenali dari awal baris, diurutkan dari yang terpanjang: //[], //-, [], **, <>, -, #, *.
  • //- dan //[] membuat entri baru yang terhubung ke entri berikutnya.
  • Baris tanpa simbol menjadi lanjutan entri terakhir. Jika belum ada entri, baris itu diabaikan dan dicatat di peringatan.
  • Spasi sampai kolom teks simbol dibuang. Indentasi yang lebih dalam tetap dipertahankan.

Contoh lengkap

Baris Judul proyek sengaja diletakkan sebelum P1 untuk menunjukkan bahwa kepala file dibuang.

Judul proyek — dibuang
P1
- Halo, kota hujan.
   lanjutan balon pertama.
//- Balon sambungan.
[] Catatan pinggir.
# Byar!
P2
** Tegasan suara.
<> Efek khusus.
* Catatan kecil.

Hasil: 2 halaman, 7 entri, 1 entri terhubung, 0 peringatan.

Batas input

Maksimal 20.000 karakter dan 2.000 baris. Input kosong atau terlalu panjang diberi pesan yang menyebut penyebabnya.

Langkah 1

Pasang APK

Hasil: MochiTs terpasang dan siap dibuka.

  1. Unduh APK dari halaman rilis GitHub.
  2. Buka berkas APK di perangkat Android 10 atau lebih baru.
  3. Jika Android memblokir pemasangan, izinkan aplikasi yang membuka berkas untuk memasang aplikasi dari sumber yang tidak dikenal.
  4. Ketuk Install, lalu buka MochiTs.
Perhatian. APK dari GitHub Actions adalah hasil build otomatis. Untuk penggunaan harian, pakai rilis yang sudah dirilis resmi bila tersedia.

Langkah berikutnya: Buat proyek →

Langkah 2

Buat proyek

Hasil: kanvas baru siap diedit.

  1. Di Home, ketuk NEW PROJECT.
  2. Isi Nama Proyek, Lebar (px), dan Tinggi (px).
  3. Pilih cepat rasio 1:1, 9:16, 16:9, atau 3:4 bila sesuai.
  4. Centang Kanvas Transparan jika latar boleh kosong.
  5. Ketuk Buat Proyek.

Langkah berikutnya: Impor halaman →

Langkah 3

Impor halaman

Hasil: halaman komik muncul sebagai lapisan gambar.

  1. Di Home, ketuk IMPORT IMAGE untuk satu atau beberapa gambar.
  2. Untuk satu chapter sekaligus, ketuk Impor ZIP.
  3. Pilih berkas dari galeri atau pengelola berkas.
  4. Tunggu halaman terbuka di editor.

Langkah berikutnya: Atur balon →

Langkah 4

Atur balon

Hasil: teks asing hilang dan area siap diisi terjemahan.

  1. Buka panel Erase.
  2. Pilih Brush untuk menambah seleksi, Eraser untuk menguranginya, Lasso untuk seleksi bebas, atau Magic Wand untuk memilih warna dengan satu ketukan.
  3. Atuk Hapus Area Terpilih. Pilih Telea (Cepat) atau LaMa (AI). Model LaMa diunduh saat pertama dipakai.
  4. Gunakan Bersihkan untuk mengosongkan seleksi atau Invert Seleksi bila perlu.
Tips. Untuk latar polos, Magic Wand lebih cepat. Atur Toleransi dan Perluas bila pinggiran masih tersisa.

Langkah berikutnya: Tambah teks →

Langkah 5

Tambah dan edit teks

Hasil: balon berisi terjemahan Indonesia.

  1. Ketuk tombol + di bar atas, lalu pilih Tambah Teks.
  2. Atau buka panel Text dan ketuk Tambah Teks ke Kanvas.
  3. Ketuk Edit Teks untuk mengubah layer yang sedang dipilih.
  4. Isi teks di Content, atur posisi di Layout, dan bentuk huruf di Style & Size.

Langkah berikutnya: Atur font →

Langkah 6

Atur font

Hasil: teks memakai font yang diinginkan.

  1. Buka panel Font dan pilih font yang tersedia.
  2. Untuk font sendiri, ketuk Impor font dan pilih berkas .ttf atau .otf.
  3. Font kustom juga bisa ditambahkan di Pengaturan → Font Manager → Tambah Font TTF/OTF Baru.

Langkah berikutnya: Simpan proyek →

Langkah 7

Simpan proyek

Hasil: berkas .mts yang bisa dibuka dan diedit lagi.

  1. Ketuk ikon Save di bar atas.
  2. Pada dialog Save As, isi Nama Output / Nama Proyek.
  3. Pilih format MTS.
  4. Pilih Folder Output, lalu simpan.
  5. Untuk membuka kembali, ketuk OPEN PROJECT di Home dan pilih berkas .mts.

Langkah berikutnya: Ekspor hasil →

Langkah 8

Ekspor hasil

Hasil: gambar siap dibagikan.

  1. Buka dialog Save As.
  2. Pilih PNG untuk latar transparan, atau JPEG / WEBP untuk berkas lebih ringan.
  3. Untuk JPEG dan WEBP, atur slider Kualitas 10–100%.
  4. Pilih Folder Output, lalu simpan.
Perhatian. JPEG tidak menyimpan transparansi. Pakai PNG bila latar harus tetap kosong.

Butuh bantuan? Lihat troubleshooting ekspor →

Pengembang

Build dari sumber

Catatan untuk yang ingin membangun APK sendiri.

Perintah build

./gradlew assembleDebug

Gunakan JDK 17. Hasil debug ada di app/build/outputs/apk/debug/.

GitHub Actions

Workflow Android Build & Sign berjalan pada push ke main. Pilih run yang sukses, lalu unduh artifact mochits-debug atau mochits-release.

Format .mts

Bundel proyek .mts adalah arsip ZIP yang berisi folder proyek dan metadata. Ekstensi ini ditetapkan di ProjectBundle.EXTENSION.

Bantuan

FAQ & troubleshooting

Masalah yang sering muncul dan cara menanganinya.

APK gagal dipasang

Cek versi Android: MochiTs butuh Android 10 atau lebih baru. Unduh ulang APK jika berkas terpotong. Jika pemasangan diblokir, izinkan aplikasi yang membuka berkas untuk memasang aplikasi dari sumber yang tidak dikenal.

Izin sumber tidak dikenal tidak ada

Buka Pengaturan Android → Keamanan atau Privasi → Pasang aplikasi tidak dikenal. Pilih browser atau pengelola berkas yang kamu pakai, lalu aktifkan izinnya.

File .mts tidak bisa dibuka

Jangan membuka .mts sebagai gambar. Di Home, ketuk OPEN PROJECT, lalu pilih berkas .mts.

Teks tidak tampil di kanvas

Buka panel Layers dan pastikan layer teks tidak disembunyikan. Periksa warna teks terhadap latar, lalu cek apakah font kustom sudah terpasang di panel Font.

Hasil ekspor tidak sesuai

Pada dialog Save As, pastikan format yang dipilih benar. PNG mempertahankan latar transparan; JPEG tidak. Untuk JPEG dan WEBP, naikkan slider Kualitas.

Model LaMa gagal diunduh

Di Pengaturan → Model Inpainting, ketuk Unduh Ulang dengan internet aktif. Sementara itu, pakai Telea (Cepat).

Naskah Script TL terbaca aneh

Cek di Cek Script. Perhatikan pemisah P1, simbol di awal baris, dan baris lanjutan setelah entri.
