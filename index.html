Dokumentasi aplikasi Android

MochiTs

Editor teks & gambar untuk typeset komik di Android. Berjalan di Android 10 (API 29) atau lebih baru.

Pakai MochiTs untuk mengganti teks asing pada halaman komik dengan terjemahan Indonesia. Kamu bisa menghapus balon lama, menulis teks baru, memilih font, lalu menyimpan proyek atau mengekspor gambar.

Unduh APK Repo GitHub

Mulai dari mana

  1. Pasang APK, lalu buat proyek.
  2. Impor halaman dan bersihkan balon.
  3. Tambah teks, atur font, lalu ekspor.

Sebelum memakai naskah terjemahan, cek dulu di Cek Script. Alat ini berjalan di browser tanpa mengirim teks ke server.

Alat

Cek Script

Periksa naskah Script TL sebelum dipakai di editor. Semua proses berjalan di browser.

Aturan naskah

  • Baris seperti P1 atau P12 membuka halaman baru. Baris sebelum pemisah pertama diabaikan.
  • Simbol dikenali dari awal baris, diurutkan dari yang terpanjang: //[], //-, [], **, <>, -, #, *.
  • //- dan //[] membuat entri baru yang terhubung ke entri berikutnya.
  • Baris tanpa simbol menjadi lanjutan entri terakhir. Jika belum ada entri, baris itu diabaikan dan dicatat di peringatan.
  • Spasi sampai kolom teks simbol dibuang. Indentasi yang lebih dalam tetap dipertahankan.

Contoh lengkap

Tempel naskah ini lalu bandingkan dengan hasilnya. Baris Judul proyek sengaja diletakkan sebelum P1 untuk menunjukkan bahwa kepala file dibuang.

Judul proyek — dibuang
P1
- Halo, kota hujan.
   lanjutan balon pertama.
//- Balon sambungan.
[] Catatan pinggir.
# Byar!
P2
** Tegasan suara.
<> Efek khusus.
* Catatan kecil.

Hasil: 2 halaman, 7 entri, 1 entri terhubung, 0 peringatan. Entri //- terhubung ke entri [] di bawahnya.

Batas input

Maksimal 20.000 karakter dan 2.000 baris. Input kosong atau terlalu panjang diberi pesan yang menyebut penyebabnya.

Panduan

Penggunaan editor

Delapan langkah dari APK terpasang sampai gambar jadi. Setiap langkah memakai tombol yang ada di aplikasi.

1. Pasang APK

Unduh APK dari halaman rilis GitHub, lalu buka berkasnya di Android. MochiTs butuh Android 10 atau lebih baru. Jika sistem meminta izin, izinkan pemasangan dari sumber yang tidak dikenal untuk aplikasi yang kamu pakai membuka berkas.

2. Buat proyek

Di Home, ketuk NEW PROJECT. Isi Nama Proyek, Lebar (px), dan Tinggi (px). Pilih cepat salah satu rasio: 1:1, 9:16, 16:9, atau 3:4. Centang Kanvas Transparan jika latar boleh kosong.

3. Impor halaman

Di Home, ketuk IMPORT IMAGE untuk satu atau beberapa gambar, atau Impor ZIP untuk satu chapter sekaligus. Halaman yang masuk muncul sebagai lapisan gambar di editor.

4. Atur balon

Buka panel Erase. Pilih Brush untuk menambah area seleksi, Eraser untuk menguranginya, Lasso untuk seleksi bebas, atau Magic Wand untuk memilih warna dengan satu ketukan. Setelah area siap, ketuk Hapus Area Terpilih. Pilih Telea (Cepat) untuk hasil langsung atau LaMa (AI) untuk hasil yang lebih halus; model LaMa diunduh saat pertama dipakai.

5. Tambah dan edit teks

Ketuk tombol + di bar atas, lalu pilih Tambah Teks. Di panel Text, ketuk Tambah Teks ke Kanvas untuk membuat layer baru atau Edit Teks untuk mengubah layer yang sedang dipilih. Atur isi di bagian Content, posisi di Layout, dan bentuk huruf di Style & Size.

6. Atur font

Buka panel Font untuk memilih font. Untuk memakai font sendiri, ketuk Impor font dan pilih berkas .ttf atau .otf. Font kustom juga bisa ditambahkan dari Pengaturan → Font Manager → Tambah Font TTF/OTF Baru.

7. Simpan proyek

Ketuk ikon Save di bar atas. Pada dialog Save As, isi Nama Output / Nama Proyek, pilih format MTS, lalu simpan. Bundel .mts bisa dibuka lagi lewat OPEN PROJECT di Home.

8. Ekspor hasil

Pada dialog Save As, pilih PNG, JPEG, atau WEBP. PNG cocok untuk latar transparan. JPEG dan WEBP punya slider Kualitas 10–100%. Pilih Folder Output sebelum menyimpan.

Pengembang

Build dari sumber

Catatan untuk yang ingin membangun APK sendiri. Tidak diperlukan untuk memakai aplikasi.

Perintah build

./gradlew assembleDebug

Gunakan JDK 17. Hasil debug ada di app/build/outputs/apk/debug/.

GitHub Actions

Workflow Android Build & Sign berjalan pada push ke main. Pilih run yang sukses, lalu unduh artifact mochits-debug atau mochits-release bila tersedia.

Format .mts

Bundel proyek .mts adalah arsip ZIP yang berisi seluruh folder proyek dan metadata. Ekstensi ini ditetapkan di ProjectBundle.EXTENSION.

Bantuan

FAQ & troubleshooting

Masalah yang sering muncul dan cara menanganinya.

APK gagal dipasang

Cek versi Android: MochiTs butuh Android 10 atau lebih baru. Unduh ulang APK jika berkas terpotong. Jika pemasangan diblokir, izinkan aplikasi yang membuka berkas untuk memasang aplikasi dari sumber yang tidak dikenal, lalu ketuk APK lagi.

Izin sumber tidak dikenal tidak ada

Buka Pengaturan Android → Keamanan atau Privasi → Pasang aplikasi tidak dikenal. Pilih browser atau pengelola berkas yang kamu pakai, lalu aktifkan izinnya. Setelah selesai, kembali ke APK dan pasang ulang.

File .mts tidak bisa dibuka

Jangan membuka .mts sebagai gambar. Di Home, ketuk OPEN PROJECT, lalu pilih berkas .mts. Jika impor gagal, periksa apakah berkas tersebut benar-benar bundel proyek MochiTs.

Teks tidak tampil di kanvas

Buka panel Layers dan pastikan layer teks tidak disembunyikan. Periksa warna teks terhadap latar, lalu cek apakah font kustom sudah terpasang di panel Font. Untuk balon yang tertutup, hapus area lama lewat panel Erase terlebih dahulu.

Hasil ekspor tidak sesuai

Pada dialog Save As, pastikan format yang dipilih benar. PNG mempertahankan latar transparan; JPEG tidak. Untuk JPEG dan WEBP, naikkan slider Kualitas. Pilih MTS jika kamu masih ingin mengedit proyek nanti.

Model LaMa gagal diunduh

Di Pengaturan → Model Inpainting, ketuk Unduh Ulang. Sambungkan ke internet lalu coba lagi. Sementara itu, pakai Telea (Cepat) yang sudah tersedia.

Naskah Script TL terbaca aneh

Cek di Cek Script. Perhatikan pemisah halaman P1, simbol di awal baris, dan baris lanjutan yang harus berada setelah entri. Baris sebelum pemisah pertama sengaja dibuang.
