MochiTs

Editor Android untuk typeset komik. Impor halaman, atur balon dan teks, lalu simpan hasilnya.

MochiTs adalah aplikasi Android untuk menata ulang teks pada halaman komik. Panduan ini berisi cara memasang aplikasi, langkah pertama memakai editor, serta pemeriksa naskah Script TL yang berjalan langsung di browser.

Unduh APK Repo GitHub

Mulai dari mana

  • Panduan penggunaan editor untuk alur kerja dasar.
  • Cek Script untuk memeriksa naskah sebelum dipakai.
  • FAQ untuk pertanyaan singkat.

Alat

Cek Script

Periksa naskah Script TL di browser. Semua proses berjalan di sisi klien; teks tidak dikirim ke server.

Cara pakai

Tempel naskah di kolom input, lalu hasil akan muncul otomatis. Aturan yang dipakai:

  • Baris P1, P2, dan seterusnya menandai halaman baru.
  • Baris diawali -, [], #, *, **, <>, atau // dibaca sebagai entri.
  • Baris dengan indentasi minimal tiga spasi menjadi lanjutan entri sebelumnya.
  • Baris kosong diabaikan. Baris yang tidak dikenali muncul sebagai peringatan.

Batas input

Maksimal 20.000 karakter dan 2.000 baris. Input kosong, terlalu panjang, atau berisi karakter tak dikenali akan diberi pesan yang jelas.

Aturan di atas dipakai sebagai default. Jika format naskahmu berbeda, beri tahu saya Supaya aturannya disesuaikan.

Panduan

Penggunaan editor

Alur dasar dari memasang APK sampai menyimpan proyek.

Memasang APK

Unduh berkas APK dari halaman rilis proyek, lalu buka berkas tersebut di perangkat Android. Jika sistem meminta izin, izinkan pemasangan dari sumber yang dikenal.

Membuat proyek pertama

Dari layar Home, pilih New Project, lalu isi nama proyek dan ukuran kanvas. Proyek baru siap dibuka di editor.

Mengenal Home

Home menampilkan daftar proyek serta tombol untuk membuat proyek baru, membuka proyek, dan mengimpor gambar.

Editor

Editor menampilkan kanvas di tengah, alat di bawah, dan panel pengaturan untuk lapisan yang sedang dipilih.

Perintah build

./gradlew assembleDebug

GitHub Actions

Build otomatis tersedia pada tab Actions di repository GitHub. Pilih workflow yang bertanda sukses untuk mengunduh hasil build.

File proyek

Proyek MochiTs disimpan dengan format .mts agar dapat dibuka kembali nanti.

FAQ

Pertanyaan umum

Jawaban singkat tentang pemasangan dan berkas proyek.

Apa itu MochiTs?

MochiTs adalah aplikasi Android untuk typeset komik: mengatur teks dan balon pada halaman yang sudah dipindai.

Bagaimana cara memasangnya?

Unduh APK dari halaman rilis proyek, lalu buka berkas tersebut di perangkat Android.

Apa format berkas proyeknya?

Proyek disimpan dengan ekstensi .mts.

Apakah Cek Script mengirim data?

Tidak. Pemeriksaan di halaman Cek Script berjalan seluruhnya di browser.
