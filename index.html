Tiga langkah pertama

Dari file mentah ke halaman jadi.

Alur yang sama dipakai untuk satu halaman latihan maupun satu chapter penuh.

01

Masukkan halaman

Pilih gambar dari galeri, atau impor satu ZIP berisi banyak halaman sekaligus.

02

Rapikan dan isi teks

Hapus teks lama dengan area seleksi, lalu isi balon dari naskah terjemahan.

03

Simpan hasilnya

Ekspor sebagai PNG, JPEG, atau WEBP. Simpan file proyek bila masih ingin mengedit.

Yang membedakan

Dibuat mengikuti kebiasaan typesetter.

Bukan sekadar editor gambar: setiap fitur mengikuti alur kerja penerjemahan komik.

Naskah jadi daftar balon

Tempel naskah TL, pilih simbol, lalu masukkan entri ke balon satu per satu. Tidak perlu menyalin ulang.

Alur di dalam aplikasi

Empat tahap, tanpa file tercecer.

Semua tersimpan dalam satu proyek. Kamu bisa berhenti kapan saja dan melanjutkan nanti.

  1. 01

    Impor halaman

    Dari galeri atau ZIP. Subfolder di ZIP otomatis menjadi folder proyek.

    Galeri · ZIP · MTS
  2. 02

    Bersihkan balon

    Tandai teks lama, lalu hapus dengan Telea atau LaMa. Hasilnya menutup rapi mengikuti latar.

    Area seleksi · Inpainting
  3. 03

    Isi teks

    Muat naskah TL, pilih entri, atur huruf dan spasi. Balon berikutnya tinggal diisi.

    Script · Tipografi
  4. 04

    Ekspor

    Simpan PNG, JPEG, atau WEBP ke folder pilihan. File proyek tetap bisa diedit.

    PNG · JPEG · WEBP
