Folder & impor ZIP

Rapikan puluhan proyek dan masukkan satu chapter penuh dalam sekali impor.

Folder proyek

Folder di MochiTs bersifat virtual: proyek tetap berupa file terpisah, hanya dikelompokkan lewat folderId. Satu proyek berada di paling banyak satu folder.

  • Buat folder: chip Kelola di Home, lalu tambahkan nama folder. Nama yang sudah dipakai akan diberi akhiran otomatis, misalnya Chapter 1 (2).
  • Pindahkan proyek: buka dialog proyek (ketuk lama), pilih Pindahkan, lalu tentukan folder atau Tanpa folder.
  • Ganti nama: dari dialog Kelola. Proyek tidak terpengaruh.
  • Hapus folder: proyek di dalamnya tidak dihapus, hanya kembali ke Tanpa folder.

Chip Semua menampilkan seluruh proyek, sedangkan chip nama folder menyaring daftar. Urutan proyek tetap berdasarkan aktivitas terakhir.

Impor banyak gambar

Ketuk ikon galeri

Picker Android terbuka. Pilih hingga 100 gambar sekaligus (batas dari aplikasi).

Folder otomatis

Jika memilih lebih dari satu gambar tanpa folder tujuan, MochiTs membuat folder Impor YYYYMMDD_HHMMSS. Satu gambar tidak dibuatkan folder.

Periksa hasilnya

Setiap gambar menjadi proyek dengan judul dari nama file. Gambar yang gagal dibaca dilewati; sisanya tetap diimpor.

Fallback picker. Jika pemilih galeri tidak tersedia, MochiTs memakai pemilih dokumen Android. Hasilnya sama.

Impor ZIP

Ada dua cara masuk: pilih ZIP langsung dari Beranda, atau bagikan ZIP dari file manager. Untuk impor dari dalam aplikasi:

Ketuk ikon ZIP

Di Beranda, ketuk ikon panah ke bawah di bar atas. Pemilih dokumen Android akan terbuka.

Pilih file ZIP

Pilih satu arsip. MochiTs memetakan isi ZIP terlebih dahulu, lalu mengimpor gambar dan bundel .mts yang ditemukan.

Periksa hasil

Notifikasi singkat menampilkan jumlah gambar dan proyek yang berhasil diimpor. Folder baru langsung muncul di Beranda.

Struktur ZIP menentukan struktur folder. MochiTs membaca arsip dalam dua lintasan: pertama memetakan isi, lalu mengekstrak hanya file yang relevan.

Isi ZIPHasil di MochiTs
001.jpg, 002.jpg, … di rootProyek-proyek di dalam satu folder bernama file ZIP.
Subfolder Ch 1/, Ch 2/Satu folder per subfolder tingkat atas; gambar di dalamnya menjadi proyek.
Campuran gambar root + subfolderGambar root masuk folder ZIP; setiap subfolder menjadi folder sendiri.
Bundel .mtsDiimpor sebagai proyek yang bisa diedit, lengkap dengan layer dan riwayatnya.
__MACOSX/, file tersembunyi, non-gambarDiabaikan.

Urutan halaman di dalam satu folder mengikuti natural sort: 2 sebelum 10, dan nama file dinormalisasi menjadi judul proyek.

Batas keamanan impor

  • Maksimal 300 item diimpor dan 5.000 entri dipindai per ZIP.
  • Maksimal 64 MB per entri dan 512 MB total data yang diekstrak.
  • Path dengan .. (traversal) serta file tersembunyi tidak diproses.
  • File sementara di cache dihapus setelah setiap entri selesai diimpor.
ZIP rusak atau terenkripsi. Jika arsip tidak bisa dibaca, impor dibatalkan dan dicatat sebagai gagal. Coba ekstrak ulang ZIP dengan aplikasi arsip lain, lalu impor kembali.

Membuka atau membagikan ZIP

MochiTs terdaftar sebagai pembuka dan target bagikan untuk application/zip dan application/x-zip-compressed. Dari file manager, pilih Bagikan lalu MochiTs, atau gunakan Buka dengan. Saat ZIP masuk dari luar:

  1. Aplikasi menampilkan dialog pratinjau berisi nama file ZIP.
  2. Ketuk Impor untuk memproses, atau Batal untuk membatalkan.
  3. Salinan sementara di cache dihapus setelah impor atau pembatalan.

Pratinjau ini sengaja dipakai agar ZIP tidak langsung diekstrak tanpa persetujuan. File .mts yang dibuka dari luar tetap langsung masuk sebagai proyek.

MochiTs belum muncul di menu Bagikan? Gunakan ikon ZIP di Beranda atau pilihan Buka dengan. Pastikan aplikasi sudah versi terbaru.
