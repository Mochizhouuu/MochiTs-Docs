Folder & impor ZIP

Rapikan puluhan proyek dan masukkan satu chapter penuh dalam sekali impor.

Folder proyek

Folder di MochiTs hanya untuk merapikan tampilan. File setiap proyek tetap terpisah, dan satu proyek hanya berada di satu folder.

  • Buat folder: buka menu tiga titik di Home, pilih Kelola folder, lalu tambahkan nama folder. Nama yang sudah dipakai akan diberi akhiran otomatis, misalnya Chapter 1 (2).
  • Pindahkan proyek: buka All Project atau isi folder, tekan lama proyek, buka menu tiga titik di bar atas, pilih Pindahkan ke folder, lalu tentukan folder atau Tanpa folder.
  • Ganti nama: dari dialog Kelola folder. Proyek tidak terpengaruh.
  • Hapus beberapa item: tekan lama satu kartu proyek atau folder, ketuk kartu lain untuk menambah pilihan, lalu ketuk ikon hapus di bar atas.
  • Hapus folder: proyek di dalamnya tidak dihapus, hanya kembali ke daftar Home tanpa folder.

Home menampilkan folder dan proyek dalam deretan Recent Projects. Kartu folder berisi cover dan jumlah proyek; ketuk kartu untuk membuka isinya dalam grid tiga kolom. Ikon panah di kanan judul membuka All Project dalam grid dua kolom. Tombol Open Project di bagian bawah khusus mengimpor berkas .mts, Import Image membuka galeri, dan Impor ZIP ada di menu tiga titik.

Di All Project, setiap folder tampil sebagai satu kartu tersendiri. Isi folder hanya muncul setelah kartu folder dibuka, jadi halaman tidak tercampur dengan daftar utama. Proyek yang tidak berada di folder tampil sebagai kartu proyek di grid yang sama.

Setiap kartu proyek memakai nama file gambar sebagai judul, tanpa ekstensi. Nama yang tampil di Home, All Project, dan isi folder berasal dari judul proyek yang sama. Urutan di dalam folder mengikuti nama file secara natural, misalnya 2 sebelum 10.

Impor banyak gambar

Ketuk Import Image

Pemilih gambar Android akan terbuka. Pilih hingga 100 gambar sekaligus (batas dari aplikasi).

Folder otomatis

Jika memilih lebih dari satu gambar tanpa folder tujuan, MochiTs membuat folder Impor YYYYMMDD_HHMMSS. Satu gambar tidak dibuatkan folder.

Periksa hasilnya

Setiap gambar menjadi proyek dengan judul dari nama file. Gambar yang gagal dibaca dilewati; sisanya tetap diimpor.

Jika galeri tidak tersedia. MochiTs memakai pemilih file bawaan Android. Hasilnya sama.

Impor ZIP

Ada dua cara masuk: pilih ZIP langsung dari Beranda, atau bagikan ZIP dari file manager. Untuk impor dari dalam aplikasi:

Buka menu tiga titik

Di Beranda, ketuk menu tiga titik di kanan atas, lalu pilih Impor ZIP. Pemilih dokumen Android akan terbuka.

Pilih file ZIP

Pilih satu file ZIP. MochiTs memeriksa isinya lebih dulu, lalu mengimpor gambar dan file proyek .mts yang ditemukan.

Periksa hasil

Notifikasi singkat menampilkan jumlah gambar dan proyek yang berhasil diimpor. Folder baru langsung muncul di Beranda.

Susunan folder di dalam ZIP menjadi susunan folder di MochiTs. Aplikasi membaca daftar isi ZIP lebih dulu, lalu hanya mengambil gambar dan file proyek yang diperlukan.

Batas keamanan impor

  • Maksimal 300 file diimpor dan 5.000 isi ZIP diperiksa untuk setiap file ZIP.
  • Maksimal 64 MB per file dan 512 MB total untuk data yang dibuka dari ZIP.
  • Alamat folder yang mencoba keluar dari ZIP (mengandung ..) dan file tersembunyi tidak diproses.
  • File sementara dihapus setelah setiap file selesai diimpor.
ZIP rusak atau terkunci. Kalau file ZIP tidak bisa dibaca, impor dibatalkan dan dicatat sebagai gagal. Coba buka ulang ZIP dengan aplikasi lain, lalu impor kembali.

Membuka atau membagikan ZIP

MochiTs bisa menerima file ZIP dari aplikasi lain. Di aplikasi File, pilih Bagikan lalu MochiTs, atau gunakan Buka dengan. Saat ZIP masuk dari luar:

  1. Aplikasi menampilkan dialog pratinjau berisi nama file ZIP.
  2. Ketuk Impor untuk memproses, atau Batal untuk membatalkan.
  3. Salinan sementara dihapus setelah impor atau pembatalan.

Pratinjau ini memastikan ZIP tidak langsung dibuka tanpa persetujuanmu. File .mts yang dibuka dari luar tetap langsung masuk sebagai proyek.

MochiTs belum muncul di menu Bagikan? Gunakan menu tiga titik di Beranda, pilih Impor ZIP, atau pakai pilihan Buka dengan. Pastikan aplikasi sudah versi terbaru.
