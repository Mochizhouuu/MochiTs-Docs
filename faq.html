FAQ

Jawaban singkat untuk masalah yang paling sering muncul. Untuk detail, ikuti tautan ke halaman terkait.

Script TL

Kenapa judul dan legenda di awal file hilang?

Itu disengaja. Semua baris sebelum pemisah halaman pertama dibuang agar kepala file tidak menjadi entri. Jika tidak ada pemisah yang cocok, tidak ada baris yang dibuang.

Kenapa P1 tidak memisahkan halaman?

Pemisah harus cocok dengan seluruh baris. Periksa spasi, karakter tak terlihat, dan pola regex di Settings. Coba paste naskah ke tester dengan pola yang sama untuk melihat hasilnya.

Apa bedanya mode gabung dan terhubung?

Gabung menambahkan teks ke entri sebelumnya (satu balon, dua baris). Terhubung membuat entri baru untuk balon berikutnya, tetapi entri itu mewarisi preset gaya dari simbol induknya, misalnya //- dari -.

Kenapa baris sambungan kehilangan sebagian spasi?

Spasi indentasi yang sejajar dengan kolom teks simbol dibuang; sisanya dipertahankan. Ini membuat baris menjorok tetap konsisten tanpa menyalin indentasi sumber. Lihat aturan indentasi.

Kenapa preset tidak mengubah ukuran font atau spasi?

Preset hanya menyimpan font, gaya font, alignment, dan bentuk kotak. Ukuran diatur lewat resize kanvas, sedangkan jarak huruf/baris diatur per layer di panel teks.

Apakah file DOCX didukung penuh?

MochiTs membaca teks dari word/document.xml; format paragraf, tabel, dan gambar di dalam DOCX tidak dipertahankan. Untuk hasil paling dapat diprediksi, gunakan TXT.

Kenapa posisi script kembali saat proyek dibuka?

Fitur Muat ulang file TL otomatis aktif secara bawaan dan menyimpan file serta posisi halaman/baris per proyek. Matikan di Settings bila tidak diinginkan.

Folder dan impor

Kenapa beberapa gambar di ZIP tidak masuk?

Periksa batas impor: maksimal 300 item, 5.000 entri dipindai, 64 MB per entri, dan 512 MB total. File non-gambar, file tersembunyi, folder __MACOSX, dan path traversal juga diabaikan.

Kenapa nama folder ZIP berbeda dari yang diharapkan?

Nama folder root diambil dari nama file ZIP. Setiap subfolder tingkat atas menjadi folder sendiri. Nama yang bentrok dengan folder yang sudah ada akan diberi akhiran otomatis seperti (2).

Apakah menghapus folder menghapus proyek?

Tidak. Proyek di dalamnya kembali ke Tanpa folder. Hapus proyek secara terpisah jika memang ingin membuangnya.

ZIP dibuka dari file manager tetapi tidak terjadi apa-apa?

MochiTs menampilkan dialog pratinjau lebih dulu; ketuk Impor. Jika dialog tidak muncul, pastikan aplikasi versi terbaru terpasang dan ZIP bertipe application/zip atau application/x-zip-compressed.

Kenapa impor banyak gambar membuat folder baru?

Memilih lebih dari satu gambar tanpa folder tujuan otomatis membuat folder Impor YYYYMMDD_HHMMSS agar proyek tidak tercampur. Satu gambar tidak dibuatkan folder.

Teks, font, dan inpainting

Font kustom tidak muncul

Pastikan file berformat .ttf atau .otf dan tidak rusak. Setelah diimpor dari Settings, font muncul di panel teks. Font yang dihapus membuat layer terkait kembali ke font default.

Jarak huruf/baris terasa tidak berubah

Kedua slider bekerja per layer teks yang sedang dipilih. Pastikan layer teks aktif. Nilai jarak baris ≤ 0 otomatis dianggap 100%; gunakan tombol Reset jarak untuk kembali ke nilai normal.

LaMa gagal diunduh atau gagal dipakai

Model berukuran ±196 MB dan diunduh sekali dari HuggingFace. Jika unduhan gagal, coba koneksi stabil dan ruang penyimpanan cukup. Saat model tidak tersedia atau gagal dimuat, inpainting otomatis memakai Telea yang offline.

Hasil inpainting masih terlihat belang

Perluas area mask sedikit melewati teks, lalu ulangi. Telea cocok untuk latar sederhana; untuk latar kompleks, gunakan LaMa. Coba beberapa kali dengan mask yang lebih rapi.

Ekspor dan penyimpanan

Di mana proyek disimpan?

Di penyimpanan internal aplikasi: database Room dan folder filesDir/projects/{id}/ berisi gambar dasar, layer, serta riwayat. Data hilang jika aplikasi di-uninstall atau data aplikasi dibersihkan.

Bagaimana cara backup proyek?

Ekspor sebagai MTS. Bundel ini menyimpan proyek lengkap dan bisa dibuka kembali atau dimasukkan ke ZIP. Menyalin folder internal secara manual tidak didukung tanpa akses root.

Ekspor gagal menulis ke folder

Izin folder bisa dicabut setelah aplikasi dipasang ulang atau penyimpanan diubah. Buka Settings, pilih ulang folder output default, lalu ekspor lagi.

File lama tertimpa

Ekspor dengan nama yang sama akan mengganti file di folder tujuan. Ganti nama output untuk menyimpan versi lain.

Kenapa hasil JPEG berbeda dari PNG?

JPEG lossy dan tidak menyimpan transparansi. Gunakan PNG untuk teks tajam atau area transparan, dan kualitas 85–95% untuk JPEG/WEBP.

Lainnya

Apakah aplikasi butuh internet?

Editing, impor, dan ekspor berjalan offline. Internet hanya dibutuhkan untuk mengunduh model LaMa pertama kali.

Apakah data dikirim ke server?

Tidak. Proyek dan naskah diproses di perangkat. Halaman tester script ini juga berjalan sepenuhnya di browser.

Aplikasi versi apa yang saya pakai?

Versi saat ini 1.0 (versionName). Build dari CI adalah build debug; pasang ulang APK terbaru untuk mendapatkan perbaikan.
