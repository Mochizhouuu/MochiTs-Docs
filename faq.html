Script TL

Kenapa judul dan legenda di awal file hilang?

Itu disengaja. Semua baris sebelum pemisah halaman pertama dibuang agar kepala file tidak menjadi entri. Jika tidak ada pemisah yang cocok, tidak ada baris yang dibuang.

Kenapa P1 tidak memisahkan halaman?

Pemisah harus cocok dengan seluruh baris. Periksa spasi, karakter tak terlihat, dan pola pemisah halaman di Settings. Tempel naskah ke tester dengan pola yang sama untuk melihat hasilnya.

Apa bedanya mode gabung dan terhubung?

Gabung menambahkan teks ke entri sebelumnya (satu balon, dua baris). Terhubung membuat entri baru untuk balon berikutnya, tetapi entri itu mewarisi preset gaya dari simbol induknya, misalnya //- dari -.

Kenapa baris sambungan kehilangan sebagian spasi?

Spasi indentasi yang sejajar dengan kolom teks simbol dibuang; sisanya dipertahankan. Ini membuat baris menjorok tetap konsisten tanpa menyalin indentasi sumber. Lihat aturan indentasi.

Kenapa preset tidak mengubah ukuran font atau spasi?

Preset hanya menyimpan font, gaya font, perataan teks, dan bentuk kotak. Ukuran huruf diatur sendiri saat mengubah kotak teks di kanvas, sedangkan jarak huruf dan baris diatur per lapisan di panel teks.

Apakah file DOCX didukung penuh?

MochiTs hanya mengambil teks dari file Word. Format paragraf, tabel, dan gambar di dalam DOCX tidak ikut terbaca. Untuk hasil yang paling mudah diprediksi, gunakan TXT.

Kenapa posisi script kembali saat proyek dibuka?

Fitur Muat ulang file TL otomatis aktif secara bawaan. MochiTs mengingat file naskah dan posisi halaman atau baris terakhir untuk setiap proyek. Matikan di Settings bila tidak diinginkan.

Folder dan impor

Kenapa beberapa gambar di ZIP tidak masuk?

Periksa batas impor: maksimal 300 item, 5.000 entri dipindai, 64 MB per file, dan 512 MB total. File selain gambar, file tersembunyi, folder __MACOSX, dan alamat folder yang mencoba keluar dari ZIP juga diabaikan.

Kenapa nama folder ZIP berbeda dari yang diharapkan?

Nama folder utama diambil dari nama file ZIP. Setiap subfolder di dalamnya menjadi folder sendiri. Kalau namanya sudah dipakai, MochiTs menambahkan akhiran seperti (2).

Apakah menghapus folder menghapus proyek?

Tidak. Proyek di dalamnya kembali ke Tanpa folder. Hapus proyeknya satu per satu kalau memang ingin dibuang.

ZIP dibuka atau dibagikan tetapi tidak terjadi apa-apa?

MochiTs menampilkan pratinjau lebih dulu; ketuk Impor. Kalau jendela itu tidak muncul, pastikan aplikasi versi terbaru sudah terpasang dan file benar-benar ZIP. Kamu juga bisa memakai menu tiga titik di Home, pilih Impor ZIP, atau pilihan Buka dengan.

Kenapa impor banyak gambar membuat folder baru?

Kalau memilih lebih dari satu gambar tanpa folder tujuan, MochiTs membuat folder Impor YYYYMMDD_HHMMSS agar proyek tidak tercampur. Satu gambar tidak dibuatkan folder.

Teks, font, dan inpainting

Font kustom tidak muncul

Pastikan file berformat .ttf atau .otf dan tidak rusak. Setelah diimpor dari Settings, font muncul di panel teks. Kalau font dihapus, lapisan yang memakainya kembali ke font bawaan.

Jarak huruf/baris terasa tidak berubah

Kedua pengatur bekerja pada lapisan teks yang sedang dipilih. Pastikan lapisan teks aktif. Kalau jarak baris diisi 0 atau kurang, MochiTs menganggapnya 100%. Gunakan tombol Reset jarak untuk kembali ke nilai normal.

LaMa gagal diunduh atau gagal dipakai

Model berukuran sekitar 196 MB dan diunduh sekali dari HuggingFace. Kalau unduhan gagal, coba koneksi yang stabil dan pastikan ruang penyimpanan cukup. Saat model belum tersedia atau gagal dimuat, MochiTs otomatis memakai Telea yang berjalan offline.

Hasil inpainting masih terlihat belang

Tandai area sedikit lebih lebar dari teks lama, lalu ulangi. Telea cocok untuk latar sederhana; untuk latar rumit, gunakan LaMa. Coba beberapa kali dengan area yang lebih rapi.

Ekspor dan penyimpanan

Di mana proyek disimpan?

Di penyimpanan internal aplikasi. Setiap proyek punya folder sendiri yang berisi gambar dasar, lapisan, dan riwayat perubahan. Data hilang kalau aplikasi dihapus dari HP atau data aplikasi dibersihkan.

Bagaimana cara backup proyek?

Ekspor sebagai MTS. File proyek ini menyimpan semuanya dan bisa dibuka lagi atau dimasukkan ke ZIP. Menyalin folder internal aplikasi secara manual tidak didukung.

Ekspor gagal menulis ke folder

Izin folder bisa hilang setelah aplikasi dipasang ulang atau penyimpanan dipindah. Buka Settings, pilih ulang folder output default, lalu ekspor lagi.

File lama tertimpa

Ekspor dengan nama yang sama akan mengganti file di folder tujuan. Ganti nama output untuk menyimpan versi lain.

Kenapa hasil JPEG berbeda dari PNG?

JPEG sedikit mengurangi kualitas gambar dan tidak menyimpan bagian transparan. Gunakan PNG untuk teks tajam atau area transparan. Untuk JPEG atau WEBP, kualitas 85 sampai 95% biasanya sudah cukup.

Lainnya

Apakah aplikasi butuh internet?

Editing, impor, dan ekspor berjalan tanpa internet. Internet hanya dibutuhkan saat pertama kali mengunduh model LaMa.

Apakah data dikirim ke server?

Tidak. Proyek dan naskah diproses di HP kamu. Tester naskah di situs ini juga berjalan sepenuhnya di browser.

Aplikasi versi apa yang saya pakai?

Versi saat ini 1.0. Bisa dilihat di Pengaturan aplikasi. File dari GitHub Actions adalah versi uji; pasang ulang APK terbaru untuk mendapatkan perbaikan.
