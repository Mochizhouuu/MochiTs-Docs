Format script TL

Ubah naskah terjemahan menjadi antrean balon: satu baris simbol, satu entri teks, satu halaman.

Contoh singkat

P1
[] Di sebuah kota yang selalu hujan,
   ada toko buku kecil di ujung gang.
- Aku datang lagi hari ini.
//- Balon sambungan tanpa ekor.
# Catatan kecil di pinggir halaman.
P2
- Lama sekali kita tidak bertemu.
* Kamu masih menulis cerita?

Hasilnya: dua halaman, enam entri. Baris pertama setelah P1 menjadi entri [], baris berspasi di bawahnya disambungkan ke entri yang sama, dan //- menjadi entri baru yang terhubung ke balon -.

Coba langsung. Buka tester script untuk melihat hasil parsing tanpa memasang aplikasi.

Pemisah halaman

Pemisah halaman adalah regex yang harus cocok dengan seluruh baris (setelah spasi tepi dibuang). Nilai bawaan:

P\d+

Dengan pola ini, baris P1, P12, dan seterusnya dianggap pemisah. Karena dicocokkan penuh, baris seperti P1 catatan bukan pemisah.

  • Label halaman diambil dari baris pemisah itu sendiri.
  • Semua baris sebelum pemisah pertama dibuang. Ini memungkinkan kepala file berisi judul, nick, atau legenda simbol tanpa ikut menjadi entri.
  • Jika tidak ada baris yang cocok, seluruh isi dianggap satu halaman dan tidak ada baris yang dibuang.
  • Halaman yang tidak punya entri tidak ditampilkan.
  • Regex tidak valid diabaikan; naskah tetap dibaca sebagai satu halaman.

Contoh alternatif: isi pemisah dengan === bila naskah memakai baris ===, atau Halaman \d+ untuk format lain.

Simbol dan mode

Setiap baris yang dimulai dengan simbol terdaftar menjadi entri baru. Simbol dicocokkan sebagai awalan, dan yang terpanjang menang, jadi ** dipilih sebelum *.

ModePerilakuContoh pemakaian
NormalMembuat entri baru dengan teks setelah simbol.- Halo.
GabungMenambahkan teks ke entri sebelumnya, dipisah baris baru. Jika belum ada entri, simbol ini tetap membuat entri baru.Dua baris dialog dalam satu balon.
TerhubungMembuat entri baru untuk balon/kotak berikutnya, sambil menandai induknya. Entri tidak digabung.//- untuk balon sambungan, //[] untuk kotak sambungan.

Simbol bawaan: [], -, //-, //[], #, *, **, <>. Kamu bisa menambah, menghapus, atau mengganti mode lewat Settings → Script.

Induk entri terhubung

Untuk simbol berawalan //, induk ditentukan dari sisa simbolnya: //- terhubung ke -, dan //[] terhubung ke []. Jika simbol hanya // tanpa sisa, induk diambil dari entri sebelumnya (atau induk entri itu, bila sebelumnya juga terhubung).

Induk dipakai untuk mewarisi preset gaya: gaya milik simbol sendiri dipakai lebih dulu; jika kosong, gaya simbol induk yang dipakai. Preset mencakup font, gaya font, alignment, dan bentuk kotak, bukan ukuran font atau spasi.

Baris sambungan dan indentasi

Baris tanpa simbol tidak dibuang selama sudah ada entri sebelumnya. Baris itu disambungkan ke entri terakhir, dengan aturan indentasi:

  • Spasi sejajar sampai kolom awal teks simbol dibuang. Contoh: - Halo punya teks mulai kolom 2; baris berikutnya yang diindentasi 2 spasi akan kehilangan 2 spasi itu.
  • Indentasi yang lebih dalam dari kolom teks dipertahankan, sehingga baris menjorok tetap menjorok.
  • Baris tanpa simbol sebelum entri pertama diabaikan.
- Aku tidak percaya
    kita benar-benar bertemu
    di tempat ini lagi.

Pada contoh di atas, baris kedua dan ketiga menjadi bagian entri -, dengan indentasi 4 spasi yang dipertahankan relatif terhadap teks simbol.

Normalisasi otomatis

Sebelum diproses, karakter berikut dibersihkan agar naskah hasil salin-tempel tetap aman:

  • BOM (U+FEFF) dan zero-width space (U+200B) dihapus.
  • Non-breaking space (U+00A0) diubah menjadi spasi biasa.
  • CRLF dan CR diubah menjadi LF.
  • Tab diubah menjadi empat spasi.

Alur kerja di aplikasi

Atur simbol dan pemisah

Buka Settings → Script. Tambahkan simbol yang dipakai naskah, tentukan mode, dan pasangkan preset gaya bila perlu.

Muat naskah di Editor

Buka panel Script TL, lalu ketuk Muat file .txt / .docx. MochiTs membaca teks dari TXT (UTF-8/UTF-16 dengan BOM) atau word/document.xml dari DOCX.

Kerjakan antrean

Panel menampilkan halaman, baris kini, dan pratinjau. Pilih layer teks lalu ketuk Masukkan; tanpa seleksi, tombol menjadi Buat baru. Gunakan Lewati untuk melewati baris.

Pindah halaman

Tombol panah di bawah antrean berpindah halaman. Ketuk baris mana pun di pratinjau untuk melompat ke baris tersebut.

Memuat ulang otomatis

Secara bawaan, file script terakhir dan posisi halaman/barisnya dimuat lagi saat proyek dibuka. Matikan opsi Muat ulang file TL otomatis di Settings bila tidak diinginkan. Data ini disimpan per proyek.

Tes file sebelum mengedit

Di Settings → Script, tombol Tes file script (.txt/.docx) membaca file dan menampilkan ringkasan: jumlah halaman, entri, entri terhubung, hitungan per simbol, dan peringatan (misalnya simbol //- dipakai tetapi belum terdaftar). Tes ini tidak mengubah antrean proyek.
