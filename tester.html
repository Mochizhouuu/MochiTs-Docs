Tester script

Uji naskah TL langsung di browser. Tidak ada data yang diunggah; semuanya diproses di perangkatmu.

Bab 052 bagian±2 menit baca
Daftar isi
Bagian Coba naskah Uji pola pemisah
Hasil di sini sama dengan di aplikasi. Tester memakai aturan yang sama: membersihkan karakter tak terlihat, memecah halaman, memilih simbol terpanjang, dan menyambung baris. Naskah tidak dikirim ke server mana pun.

Coba naskah

Input

Tempel naskah asli. Karakter tak terlihat dan tab dirapikan otomatis.
Pola harus sama dengan seluruh baris. Kosongkan bila naskah tidak memakai pemisah halaman.
Satu simbol per baris. Tanpa keterangan berarti mode normal.

Hasil

Uji pola pemisah

Di bagian ini kamu bisa mencoba pola pemisah dan melihat baris mana yang cocok. Contoh: pola P\d+ cocok dengan P1 dan P12. Untuk pola sederhana, hasil di browser dan di aplikasi sama.

Kecocokan

Daftar kecocokan:
Gunakan pola sederhana. Fitur pola tingkat lanjut bisa berbeda antara browser dan aplikasi. Untuk pemisah halaman, cukup gunakan pola seperti P\d+, ===, atau Halaman \d+.
Privasi. Semua pengujian berjalan di browser. Naskah yang ditempel tidak dikirim ke server dan hilang saat halaman ditutup.
