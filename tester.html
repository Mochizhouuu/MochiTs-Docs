Tester script

Uji naskah TL langsung di browser. Tidak ada data yang diunggah; semuanya diproses di perangkatmu.

Bagaimana ini bekerja? Tester memakai aturan yang sama dengan ScriptParser.kt: normalisasi karakter, pemisah halaman regex full-match, pencocokan simbol terpanjang, entri gabung/terhubung, dan indentasi sambungan. Hasil akhir di aplikasi tetap diproses oleh Kotlin.

Parser naskah

Input

Tempel naskah asli. Tab, CRLF, BOM, dan NBSP dinormalisasi otomatis.
Harus cocok dengan seluruh baris. Kosongkan untuk menonaktifkan pemisah.
Satu simbol per baris. Tanpa keterangan berarti mode normal.

Hasil

Lab regex pemisah

Coba pola lain untuk memastikan baris pemisah cocok persis. Lab ini memakai RegExp JavaScript; aplikasi memakai regex Kotlin/Java, yang umumnya sama untuk pola sederhana.

Kecocokan

Daftar match:
Perbedaan mesin regex. Fitur khusus seperti lookbehind, named group, atau \p{...} bisa berbeda antara JavaScript dan Java. Untuk pemisah halaman, gunakan pola sederhana seperti P\d+, ===, atau Halaman \d+.
Privasi. Halaman ini statis. Naskah yang ditempel tidak dikirim ke server mana pun dan hilang saat halaman ditutup.
