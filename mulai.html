Mulai & instalasi

Dari memasang APK sampai proyek pertamamu siap diedit. Tidak ada akun, tidak ada langganan.

Memasang aplikasi

MochiTs adalah aplikasi Android native (Kotlin + Compose) dengan minimum Android 10 (API 29). Ada dua cara mendapatkan APK:

  • Artifact dari CI — buka GitHub Actions, pilih workflow terbaru yang hijau, lalu unduh artifact app-debug. Perlu login GitHub.
  • Build sendiri — clone repo, lalu jalankan ./gradlew assembleDebug dengan JDK 17. APK ada di app/build/outputs/apk/debug/.
Instal dari file. Setelah APK diunduh, buka lewat file manager. Jika Android memblokir, izinkan Install unknown apps untuk aplikasi file manager tersebut, lalu coba lagi.
Build debug. Artifact CI adalah build debug: ukurannya lebih besar, dan data bisa hilang jika aplikasi di-uninstall. Jangan gunakan untuk distribusi publik.

Membuat proyek pertama

Buka Home

Semua proyek muncul di daftar, diurutkan dari yang terakhir dibuka. Folder ditampilkan sebagai chip di bagian atas.

Ketuk tombol buat proyek

Isi nama, lebar, dan tinggi kanvas dalam piksel. Centang Kanvas Transparan bila ingin latar kosong; jika tidak, pilih warna latar.

Pilih gambar atau mulai kosong

Kamu bisa langsung membuat kanvas kosong, atau mengimpor gambar dari galeri sebagai halaman pertama.

Mulai mengedit

Editor terbuka dengan toolbar kiri, kanvas di tengah, dan panel properti untuk layer yang sedang dipilih.

Mengenal Home

Home adalah pusat proyek. Beberapa elemen penting:

ElemenFungsi
Chip folderMenyaring proyek. Semua menampilkan seluruh proyek, Tanpa folder hanya proyek yang belum dikelompokkan.
KelolaMembuat, mengganti nama, dan menghapus folder. Proyek di folder yang dihapus tidak ikut terhapus.
Ikon ZIPMengimpor arsip ZIP berisi gambar halaman dan/atau subfolder.
Ikon galeriMemilih beberapa gambar sekaligus. Lebih dari satu gambar otomatis dibuatkan folder.
Ketuk lama proyekMembuka dialog proyek: buka, pindahkan ke folder, ganti nama, atau hapus.

Mengenal Editor

  • Kanvas — cubit untuk zoom, geser dua jari untuk pan. Ketuk dua kali layer teks untuk mengedit isinya.
  • Toolbar — pilih alat (brush, eraser, lasso, magic wand), teks, atau layer gambar.
  • Panel layer — urutkan, sembunyikan, kunci, dan hapus layer.
  • Panel properti — pengaturan khusus layer terpilih: font, warna, stroke, spasi, dan lainnya.
  • Undo/redo — riwayat disimpan ke disk, jadi tetap tersedia setelah aplikasi ditutup.
Autosave. Tidak ada tombol simpan. Setiap perubahan disimpan otomatis; kembali ke Home kapan saja.

Tiga kebiasaan yang menghemat waktu

  1. Kelompokkan proyek per judul atau chapter memakai folder sejak awal.
  2. Simpan naskah TL dalam satu file teks, lalu gunakan format script agar balon terisi otomatis.
  3. Atur jarak huruf/baris di panel teks sebelum menyalin gaya ke balon lain.
