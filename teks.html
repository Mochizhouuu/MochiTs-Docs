Teks & spasi

Semua yang bisa diatur pada layer teks, termasuk dua slider yang paling sering dipakai untuk merapikan balon.

Membuat dan mengedit teks

  • Pilih alat teks di toolbar, lalu ketuk kanvas untuk membuat layer baru.
  • Ketuk dua kali layer teks untuk membuka editor isi.
  • Layer teks punya bentuk BOX (kotak) atau OVAL; pilihan bentuk memengaruhi area pembungkusan baris.
  • Teks dibungkus ulang (reflow) saat lebar kotak berubah, dengan dukungan hyphenation Indonesia dan Inggris.

Font dan ukuran

Font bawaan bisa diganti lewat panel teks. Untuk font kustom:

Buka Settings → Font

Impor file .ttf atau .otf dari penyimpanan.

Pilih font di panel teks

Font kustom muncul bersama font bawaan. Gaya Regular, Bold, Italic, dan Bold Italic mengikuti file yang tersedia.

Hapus jika tidak dipakai

Font kustom bisa dihapus dari Settings. Proyek yang memakai font tersebut perlu mengganti fontnya.

Jarak huruf dan jarak baris

Di panel teks, bagian Style & Size berisi dua slider spasi. Keduanya bekerja per layer dan langsung terlihat di kanvas.

SliderRentangArti nilai
Jarak huruf −5% sampai 20% Ditampilkan sebagai persen dari ukuran font (em). 0% = normal, 10% = tiap huruf diberi ruang tambahan 0,1 em.
Jarak baris 80% sampai 200% Pengali tinggi baris. 100% = normal, 120% = baris lebih renggang, 80% = lebih rapat.
  • Nilai jarak baris ≤ 0 dianggap tidak valid dan otomatis kembali ke 100% saat dirender.
  • Jarak huruf ikut diperhitungkan saat mengukur lebar minimum kotak dan saat menggambar, jadi teks tidak terpotong.
  • Tombol Reset jarak mengembalikan keduanya ke 0% dan 100%.
Kapan dipakai? Jarak huruf membantu teks kapital yang terasa sempit; jarak baris membantu balon dengan banyak baris agar tidak menempel. Untuk teks vertikal, kedua nilai tetap diterapkan mengikuti arah aliran.

Warna, stroke, glow, dan gradient

  • Warna & opasitas: warna isi teks dan transparansinya.
  • Stroke: ketebalan dan opasitas garis tepi; berguna untuk teks di atas latar ramai.
  • Drop shadow: radius serta offset X/Y.
  • Glow: radius dan warna cahaya di belakang teks.
  • Gradient: dua warna atau lebih, arah horizontal/vertikal, atau sudut bebas. Minimal dua stop agar aman.
  • Motion blur: blur searah sudut tertentu untuk kesan gerak.

Menghapus teks lama (inpainting)

Sebelum menempel teks baru, bersihkan teks asli memakai tool seleksi:

  • Brush dan Eraser: melukis/menghapus mask.
  • Lasso: seleksi area bebas.
  • Magic Wand: flood fill berdasarkan toleransi warna, dengan opsi pelebaran margin (expand) dan invert mask.

Setelah mask siap, jalankan inpainting:

  • Telea (OpenCV): cepat dan sepenuhnya offline. Cocok untuk latar sederhana.
  • LaMa AI: model ONNX ±196 MB, diunduh sekali dari HuggingFace ke folder model aplikasi. Jika model belum ada atau gagal dimuat, MochiTs otomatis memakai Telea.
Unduhan model. Sediakan koneksi stabil untuk unduhan pertama. Setelah tersimpan di perangkat, LaMa bisa dipakai offline. Unduhan yang terputus disimpan sebagai file .tmp dan tidak dipakai sampai selesai.
